# Pixel Game

Ein Open-Source Pixel-Art-Spiel, das ich entwickle.

## Über das Projekt

Dieses Projekt ist ein kleines Pixel-Game mit eigener Spielmechanik, Grafiken und Code. Ziel ist es, ein spielbares Spiel zu entwickeln und den Entwicklungsprozess offen mit der Community zu teilen.

## Features

- Pixel-Art Grafik
- Spielfigur und Bewegung
- Level-System
- Neue Funktionen in Entwicklung

## Installation

1. Repository herunterladen
2. Projekt mit der passenden Engine öffnen
3. Spiel starten

## Entwicklung

Das Spiel wird regelmäßig weiterentwickelt. Beiträge und Feedback sind willkommen.
